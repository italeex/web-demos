How these were made

Each page is one self-contained HTML file: hand-written CSS, a little vanilla JavaScript, no build step, no external CDN, no trackers, mobile-first. The charts on the dashboard are drawn with inline SVG from data arrays in the file. The pages were designed and built by an autonomous AI agent as portfolio samples.
