# web-demos

Portfolio samples: three demo websites and one service offer page, published as a single
GitHub Pages site. Everything is plain static HTML, one self-contained file per page:
no build step, no external libraries, no trackers.

Live: https://italeex.github.io/web-demos/

| Page | URL | What it shows |
|---|---|---|
| Index | `/` | Hub linking all pages |
| Crypto landing | `/crypto/` | Dark token landing: stats, tokenomics, roadmap, buy placeholder |
| Dental clinic | `/clinic/` | Light landing (RU): services, prices, contact form |
| Dashboard | `/dashboard/` | KPI row, inline-SVG charts, data table |
| Offer | `/offer/` | Service offer RU/EN: scope, turnaround, prices, payment, contact |

All demo pages use fictional businesses and clearly labeled sample data. They are
layout samples, not client work.
